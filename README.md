# eux-acl-generator

Dette er et verktøy for å generere diverse filsett som trengs for å vise SEDer på ulike formater.

Den viktigste oppgaven er at den trekker ut diffen mellom ulike versjoner og i fortsettelsen av det er et verktøy for å lage nye versjoner av ACLen. 


Filsett som genereres:
* ACL-maler
* PDF-maler
* Testdata
* Kodeverksfiler som brukes av ACL- og PDF-malene

Mer info? Se [dokumentasjon.](Dokumentasjon.md) Forhåpentligvis gir den et godt grunnlag for å jobbe videre med koden.
